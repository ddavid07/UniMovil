# Seguridad

## Versiones soportadas

La rama `main` es la única línea de desarrollo soportada actualmente. Todavía no hay versiones publicadas.

## Informar de una vulnerabilidad

No publiques vulnerabilidades sin corregir en issues ni en pull requests. Utiliza la opción **Report a vulnerability** de la pestaña **Security** del repositorio para enviar un aviso privado. Si esa opción no estuviera disponible, contacta de forma privada con el mantenedor `@ddavid07` en GitHub.

Incluye los pasos para reproducir el problema, el impacto observado y cualquier mitigación conocida. No adjuntes datos personales ni secretos reales.

## Gestión

El equipo confirmará la recepción, investigará el informe y coordinará una corrección antes de publicar detalles. No se garantiza un plazo de respuesta mientras UniMovil siga siendo un proyecto académico sin equipo de seguridad dedicado.
