# Scripts del repositorio

Los scripts de automatización que no pertenecen a una aplicación concreta se ubican aquí. Deben ser reproducibles, aceptar la configuración mediante argumentos o variables de entorno, no contener credenciales y documentar cualquier efecto sobre los datos.

Los comandos habituales de desarrollo y calidad se mantienen como scripts npm en el `package.json` raíz para que el equipo utilice una única interfaz.
