# Requisitos

Esta carpeta reúne la base del producto, el catálogo funcional y las historias de usuario de UniMovil. Los documentos describen el alcance vigente y distinguen las capacidades implementadas de las que siguen propuestas o dependen de información aún no disponible.

## Documentos

- [Fundamentos del producto](product-foundations.md): propósito, alcance geográfico, perfiles, principios y plataformas.
- [Catálogo funcional](functional-catalog.md): capacidades del producto y estado actual por área funcional.
- [Historias de usuario](user-stories/README.md): las 69 historias y sus criterios de aceptación.

El [Product Backlog](../backlog/product-backlog.md) es la fuente de orden, prioridad, estado y evidencia por historia. Los [planes de Sprint](../iterations/README.md) documentan los incrementos y las propuestas futuras. Este índice resume los documentos de requisitos y no sustituye esas fuentes.
