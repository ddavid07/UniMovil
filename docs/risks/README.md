# Riesgos

Esta carpeta reúne el seguimiento transversal de los riesgos de UniMovil. El registro complementa los riesgos específicos de cada Sprint y los límites documentados en los ADR; no sustituye esos documentos ni presenta los planes futuros como trabajo completado.

## Documentos

- [Plan de Reducción, Supervisión y Gestión del Riesgo](risk-management-plan.md): método de valoración, registro priorizado y respuestas para los riesgos vigentes.

## Uso del registro

El plan se revisa cuando cambia una fuente, una decisión, una dependencia o el alcance operativo del producto, y al preparar o cerrar un Sprint. Las actas de reuniones solo se incorporan a [meetings](../meetings/) si esas reuniones se celebran.
