# Iteraciones

Los planes y resultados de los Sprints se versionan en esta carpeta. Todos siguen una estructura común: Sprint Goal y valor, Sprint Backlog, alcance y decisiones, responsabilidades por rol, plan de trabajo, riesgos, verificación y, para los Sprints cerrados, incremento y cierre. La [plantilla de Sprint](sprint-template.md) sirve de base para nuevos planes.
