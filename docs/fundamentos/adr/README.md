# Architecture Decision Records

Los ADR registran decisiones técnicas importantes y evitan que el equipo dependa de conversaciones dispersas.

## Formato

Cada ADR utiliza esta estructura:

```text
# ADR-NNNN — Título

## Estado

Aceptada | Propuesta | Reemplazada | Rechazada

## Contexto

## Decisión

## Alternativas consideradas

## Consecuencias

## Fecha
```
