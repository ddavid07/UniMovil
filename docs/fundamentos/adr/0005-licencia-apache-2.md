# ADR-0005 — Apache License 2.0

## Estado

Aceptada

## Contexto

UniMovil es un proyecto académico que puede ser reutilizado por otras personas o por la universidad. Se busca permitir uso, modificación y redistribución manteniendo condiciones claras.

## Decisión

El código de UniMovil se distribuirá bajo Apache License 2.0. El archivo `LICENSE` del repositorio identifica como titular a `Equipo UniMovil`.

## Alternativas consideradas

- MIT.
- GPLv3.

## Consecuencias

### Positivas

- Permite reutilización y modificación.
- Incluye una concesión explícita relacionada con patentes.
- Es adecuada para colaboración y posible reutilización institucional.

### Negativas

- Tiene más requisitos de atribución que MIT.
- Las dependencias y materiales de terceros mantienen sus propias licencias.
- La licencia del código no concede derechos sobre marcas, logotipos o datos de la UCM.
