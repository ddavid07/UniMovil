# Presentaciones

Aquí se guardarán las fuentes y materiales de presentación que se creen para UniMovil. Los archivos se incorporarán cuando exista contenido nuevo y revisado; no se trasladan presentaciones ni exportaciones anteriores.

Cuando una presentación explique el resultado de una iteración, enlázala desde su registro en `iterations/` y conserva aquí la fuente editable junto con las exportaciones necesarias.
